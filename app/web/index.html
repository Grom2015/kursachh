Как это работает

Выберите тикер, добавьте официальный PDF, дальше система сама запускает проверку документа, извлечение таблиц, поиск фактов, расчет доступных коэффициентов и сборку JSON для анализа.

Загрузка отчета

Поддерживаются PDF, XLSX, HTML, HTM и ZIP. После загрузки автоматически запускается полный черновой анализ без записи фактов в БД.
